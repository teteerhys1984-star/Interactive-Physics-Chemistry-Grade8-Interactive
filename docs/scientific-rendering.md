# Scientific rendering rules

Arabic prose stays RTL. Every scientific token is an isolated LTR component (`dir="ltr"` and `unicode-bidi: isolate`). `NuclearNotation` uses separate mass, atomic, symbol, and charge DOM nodes. Its numbers intentionally sit to the left of the element symbol, with mass above atomic; this is the correct scientific layout and must not be changed as a cosmetic RTL fix. Atomic-only notation does not render an empty mass placeholder. Chemical formulas use semantic `sub`; ion charge is a separate `sup` node. Mathematical notation is rendered by KaTeX through `MathInline` and `MathBlock`, never by generic text. KaTeX fractions must remain true stacked fractions with numerator above denominator, including inline formulas, blocks, lesson explanations, and worked solutions.

Unit tests assert structure and contracts; they do not prove visual appearance. A browser preview inspection is required before adding lessons. Future lessons must preserve the RTL/LTR isolation rules for all mixed Arabic and scientific content.
